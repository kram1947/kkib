## ✨ Features

- **⏱️ Timed Assessments** - Real exam conditions with countdown timer
- **📊 Progress Tracking** - Visual progress bar and question navigator
- **📄 PDF Reports** - Downloadable results with detailed feedback
- **📖 Study Materials** - Interactive guides with diagrams and quizzes
- **🎯 Multiple Question Types** - MCQ, short answer, and interactive exercises
- **💾 Local History** - Saves progress and results in browser
- **🖱️ Interactive Content** - Click-to-reveal images and activities (Genetics Basics)
- **📈 Subject-Based Filtering** - Filter assessments by subject (Math, I&S, Science, BioTech)

## 🛠️ Tech Stack

- **Frontend**: React, Vite, CSS3
- **Deployment**: [Vercel](https://vercel.com)
- **Version Control**: GitHub
- **Study Materials**: Vanilla HTML5 with interactive JavaScript

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/kram1947/kkib.git
   cd kkib/source
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   # Opens at http://localhost:5173
   ```

4. **Build for production**
   ```bash
   npm run build
   # Output in dist/ folder
   ```

5. **Deploy to Vercel** (automatic)
   - Push to GitHub
   - Vercel auto-deploys from main branch

## 🎓 IB Curriculum

### MYP4 (Middle Years Programme)
- **Mathematics**: Number, Algebra, Geometry, Trigonometry, Statistics, Probability
- **Individuals & Societies**: Money & Economy, Supply & Demand
- **Science**: Ions, Isotopes, Ionic Bonding

### MYP (General)
- **BioTechnology**: Genetics Basics (introduction to all topics)

### DP (Diploma Programme)
**Standard Level (SL) & Higher Level (HL):**
- Topic 3.1: Genes
- Topic 3.2: Chromosomes
- Topic 3.3: Meiosis
- Topic 3.4: Inheritance
- Topic 3.5: Genetic Modification & Biotechnology

**Higher Level (HL) Only:**
- Topic 7: Nucleic Acids
- Topic D2.2: Gene Expression
- Topic 10: Advanced Genetics & Evolution
