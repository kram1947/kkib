Dihybrid crosses, gene linkage, and Chi-squared test

Dihybrid Crosses

Definition: A genetic cross examining the inheritance of TWO different traits simultaneously. Uses a 4×4 Punnett square (16 boxes).

Example: Seed Color (Y=yellow, y=green) and Seed Shape (R=round, r=wrinkled)

Cross: YyRr × YyRr (heterozygous for both traits)

YR Yr yR yr
YR YYRR YYRr YyRR YyRr
Yr YYRr YYrr YyRr Yyrr
yR YyRR YyRr yyRR yyRr
yr YyRr Yyrr yyRr yyrr

Phenotypic Ratio: 9 Yellow Round : 3 Yellow Wrinkled : 3 Green Round : 1 Green Wrinkled

9:3:3:1 ratio is classic for dihybrid crosses with independent assortment

Gene Linkage

Definition: Genes located close together on the same chromosome tend to be inherited together (do not assort independently).

Key Concepts

  • Linked genes: On same chromosome, inherited together
  • Recombination (crossing over): Can separate linked genes
  • Linkage map: Shows relative positions of genes on chromosome
  • Centimorgans (cM): Unit of distance (1% recombination = 1 cM)

Linked vs. Unlinked Genes

Feature Unlinked (Independent Assortment) Linked Genes
Location Different chromosomes OR far apart on same chromosome Close together on same chromosome
Punnett Ratio 9:3:3:1 (dihybrid) More parental types, fewer recombinants
Recombination Not applicable Crossing over can separate them

Chi-Squared (χ²) Test

Purpose: Statistical test to determine if observed results differ significantly from expected results (null hypothesis).
χ² = Σ [(Observed - Expected)² / Expected]

Steps to Perform Chi-Squared Test

  1. State null hypothesis: "No significant difference between observed and expected"
  2. Calculate expected values: Based on known ratios (e.g., 9:3:3:1)
  3. Calculate χ²: Use formula for each category, sum them
  4. Determine degrees of freedom (df): df = number of categories - 1
  5. Compare to critical value: Use χ² table at p=0.05
  6. Conclusion: If χ² calculated < critical value → accept null hypothesis

Example Calculation

Cross: Dihybrid (YyRr × YyRr), expected ratio 9:3:3:1

Total offspring: 160

  • Expected: 90 Yellow Round, 30 Yellow Wrinkled, 30 Green Round, 10 Green Wrinkled
  • Observed: 85, 32, 28, 15
  • χ² = (85-90)²/90 + (32-30)²/30 + (28-30)²/30 + (15-10)²/10 = 0.278 + 0.133 + 0.133 + 2.5 = 3.044
  • df = 4-1 = 3 → Critical value (p=0.05) = 7.815
  • 3.044 < 7.815 → Accept null hypothesis (difference is due to chance)

Degrees of Freedom and Critical Values

df Critical Value (p=0.05) Application
1 3.841 Monohybrid cross (2 categories)
3 7.815 Dihybrid cross (4 categories)
2 5.991 Chi-squared for 3 categories

Linkage Maps

Gene mapping: Using recombination frequencies to determine relative positions of genes on a chromosome.

Example: Drosophila (Fruit Fly)

  • Body color (B) and wing size (W) are 18 cM apart
  • 18% recombination frequency = 18 cM
  • Genes closer together have lower recombination frequencies
  • Maximum recombination = 50% (genes behave as unlinked)
