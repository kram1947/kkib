📝 Algebraic Expressions

Simplifying, expanding, and factoring algebraic expressions (Haese Chapter 6)

Key Concepts

An algebraic expression contains variables, constants, and operation signs. Learning to manipulate these is fundamental to algebra.

Terms: \(3x^2, -5y, 7\)
Like Terms: \(3x, -5x\) (same variable)
Remember: Only like terms can be combined. \(3x + 5x = 8x\), but \(3x + 5y\) cannot be combined.

Expanding Brackets

Use the distributive law to remove brackets:

\(a(b + c) = ab + ac\)
\((a + b)(c + d) = ac + ad + bc + bd\)

📝 Example 1: Expanding

Expand: \(3(x + 4)\)

\(= 3x + 3(4) = 3x + 12\)

Factoring

Reverse of expanding - take out a common factor:

\(3x + 12 = 3(x + 4)\)
\(x^2 + x = x(x + 1)\)

Difference of Squares

Special factoring pattern:

\(a^2 - b^2 = (a+b)(a-b)\)
\(x^2 - 9 = (x+3)(x-3)\)

📝 Example 2: Full Factorization

Factor fully: \(2x^2 - 8\)

Step 1: Take out common factor 2: \(2(x^2 - 4)\)

Step 2: Factor difference of squares: \(2(x + 2)(x - 2)\)

Solving equations of the form ax + b = c (Haese Chapter 7)

Solving Linear Equations

The goal is to isolate the variable. Use inverse operations:

If \(ax + b = c\)
Then \(x = \frac{c - b}{a}\)

📝 Example 3: Basic Solve

Solve: \(3x + 7 = 22\)

\(3x = 22 - 7 = 15\)

\(x = 15 ÷ 3 = 5\)

📝 Example 4: Fraction Solution

Solve: \(\frac{x}{4} - 3 = 2\)

\(\frac{x}{4} = 5\)

\(x = 20\)

🌍 Real-World: Distance Problem

Problem: A train travels 240 km in x hours at 80 km/h. Find x.

Solution: distance = speed × time

\(240 = 80x\)

\(x = 240 ÷ 80 = 3\) hours

🔢 Simultaneous Equations

Solving systems of two linear equations (Haese Chapter 8)

Methods

  • Substitution: solve one eq for one variable, substitute into other
  • Elimination: add/subtract equations to eliminate a variable
  • Graphical: find where lines intersect

Interactive: Graphical Solution

Intersection: (?, ?)

Worked Examples

📝 Example 7: Substitution

Solve: y = 2x + 1, x + y = 7

Substitute: x + (2x + 1) = 7

3x + 1 = 7 → 3x = 6 → x = 2

y = 2(2) + 1 = 5

Answer: (2, 5)

📝 Example 8: Elimination

Solve: 2x + y = 8, x - y = 1

Add equations: 3x = 9 → x = 3

Substitute: 3 - y = 1 → y = 2

Answer: (3, 2)

🌍 Real-World: Ticket Problem

Problem: 50 tickets sold for $200. Adult tickets $5, child $3. How many of each?

Let: a = adults, c = children

a + c = 50

5a + 3c = 200

Solution: From first: c = 50 - a

Substitute: 5a + 3(50-a) = 200

5a + 150 - 3a = 200 → 2a = 50 → a = 25

c = 50 - 25 = 25 adults, 25 children

📉 Quadratic Equations

Solving equations of the form ax² + bx + c = 0 (Haese Chapter 9)

Methods of Solving

  • Factoring: if possible to factor
  • Square Root: if bx = 0
  • Quadratic Formula: always works!
\(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)

The discriminant: \(D = b^2 - 4ac\)

D valueRoots
D > 0Two real roots
D = 0One real root
D < 0No real roots

Worked Examples

📝 Example 9: Factoring

Solve: x² + 5x + 6 = 0

Factor: (x + 2)(x + 3) = 0

x = -2 or x = -3

📝 Example 10: Quadratic Formula

Solve: x² - 3x - 4 = 0

a=1, b=-3, c=-4

D = (-3)² - 4(1)(-4) = 9 + 16 = 25

x = (3 ± 5)/2 = 4 or -1

Interactive: Quadratic Graph

Roots: x = 4, x = -1

🌍 Real-World: Projectile Motion

Problem: A ball is thrown up with velocity 30 m/s from height 0. When does it hit the ground? (h = 30t - 5t²)

Solve: 30t - 5t² = 0

5t(6 - t) = 0

t = 0 (launch) or t = 6 seconds (lands)

🔄 Functions

Understanding functions, domain, range, and inverses (Haese Chapter 10)

Function Notation

A function maps each input to exactly one output:

f(x) = 2x + 3
f(2) = 2(2) + 3 = 7
Vertical Line Test: If a vertical line crosses a graph more than once, it's not a function.

Domain & Range

  • Domain: all possible x-values
  • Range: all possible y-values

📝 Example 11

f(x) = x², domain = all real numbers

Range = all non-negative: y ≥ 0

Inverse Functions

Swap x and y, solve for the new y:

If f(x) = 2x + 1
Let y = 2x + 1
x = 2y + 1 → y = (x-1)/2
f⁻¹(x) = (x - 1)/2

Composite Functions

Apply one function to the result of another:

f(x) = x + 2, g(x) = x²
f(g(x)) = x² + 2
g(f(x)) = (x + 2)²

🔢 Sequences & Series

Arithmetic and geometric sequences (Haese Chapter 11)

Arithmetic Sequences

Each term increases by a constant difference:

\(a_n = a_1 + (n-1)d\)

where d = common difference

📝 Example 12

Sequence: 5, 8, 11, 14, ...

d = 3, a₁ = 5

a₁₀ = 5 + 9(3) = 32

Geometric Sequences

Each term is multiplied by a constant ratio:

\(a_n = ar^{n-1}\)

where r = common ratio

📝 Example 13

Sequence: 2, 6, 18, 54, ...

r = 3, a = 2

a₅ = 2 × 3⁴ = 2 × 81 = 162

Interactive: Sequence Visualization

Terms: 2, 4, 6, 8, 10...

Series: The sum of terms in a sequence. Arithmetic series: Sₙ = n(a₁ + aₙ)/2 or Sₙ = n[2a₁ + (n-1)d]/2

🌍 Real-World Applications

How algebra is used in various fields

💰 Finance

Compound Interest:

\(A = P(1 + r)^n\)

P = principal, r = rate, n = years

📏 Architecture

Structural Load:

Linear equations model stress distribution across beams.

🌡️ Science

Temperature (C to F):

\(F = \frac{9}{5}C + 32\)

📱 Technology

Computer Growth:

Moore's Law: computing power doubles every 2 years (exponential).

🏃 Sports

Training Pace:

Use linear equations to predict race times based on training data.

🌱 Biology

Population Growth:

Exponential models for bacteria growth: N = N₀eᵏᵗ

🌍 Comprehensive: Investment Growth

Scenario: $10,000 invested at 7% annual compound interest. How much after 10 years?

Solution: A = 10000(1 + 0.07)¹⁰

A = 10000 × 1.967 ≈ $19,670

The investment nearly doubles in 10 years!
