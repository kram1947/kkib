Detailed mechanisms of DNA replication, transcription, and translation

DNA Structure Review

DNA (Deoxyribonucleic Acid): Double-stranded helix composed of nucleotides (deoxyribose sugar + phosphate + nitrogenous base).

DNA Base Pairing

A=T (Adenine-Thymine, 2 H-bonds)
G≡C (Guanine-Cytosine, 3 H-bonds)

DNA vs. RNA Comparison

Feature DNA RNA
Sugar Deoxyribose Ribose
Bases A, T, G, C A, U, G, C
Strands Double-stranded Single-stranded
Function Store genetic information Protein synthesis

DNA Replication

Definition: The process by which DNA makes a copy of itself. Semi-conservative (each new DNA molecule has one old and one new strand).

🔬 Steps of DNA Replication

  1. Initiation: Helicase unwinds DNA double helix, creating replication fork
  2. Primer Binding: RNA primer binds to template strand (provided by primase)
  3. Elongation: DNA polymerase III adds nucleotides in 5'→3' direction
  4. Leading Strand: Synthesized continuously toward replication fork
  5. Lagging Strand: Synthesized discontinuously as Okazaki fragments
  6. Primer Removal: DNA polymerase I removes RNA primers, replaces with DNA
  7. Ligation: DNA ligase joins Okazaki fragments

Key Enzymes in Replication

Enzyme Function
Helicase Unwinds DNA double helix
DNA Polymerase III Adds nucleotides to growing DNA strand
DNA Polymerase I Removes RNA primers, replaces with DNA
DNA Ligase Joins Okazaki fragments together
Primase Synthesizes RNA primers

Transcription (DNA → RNA)

Definition: The process of making mRNA from a DNA template. Occurs in the nucleus.

📝 Steps of Transcription

  1. Initiation: RNA polymerase binds to promoter region on DNA
  2. Elongation: RNA polymerase unwinds DNA and adds RNA nucleotides (5'→3')
  3. Termination: RNA polymerase reaches terminator sequence, mRNA is released
  4. Processing (Eukaryotes): 5' cap added, poly-A tail added, introns removed (splicing)

Transcription vs. Replication

Feature Replication Transcription
Product DNA mRNA
Template Both DNA strands One DNA strand (gene)
Enzyme DNA polymerase RNA polymerase
Occurs Before cell division When protein is needed

Translation (RNA → Protein)

Definition: The process of building a protein from mRNA. Occurs at ribosomes in the cytoplasm.

🧬 Steps of Translation

  1. Initiation: mRNA binds to small ribosomal subunit; start codon (AUG) recruits initiator tRNA
  2. Elongation: tRNA brings amino acids; ribosome moves along mRNA, adding amino acids to growing polypeptide
  3. Codon Recognition: Each tRNA anticodon matches mRNA codon (e.g., AUG → Methionine)
  4. Termination: Stop codon (UAA, UAG, UGA) reached; release factor binds, polypeptide released

The Genetic Code

  • 64 codons (4³ = 64 possible 3-base combinations)
  • 61 codons code for amino acids
  • 3 stop codons (UAA, UAG, UGA)
  • AUG is start codon (codes for Methionine)
  • Code is universal (nearly all organisms use same code)
  • Code is degenerate (multiple codons can code for same amino acid)
